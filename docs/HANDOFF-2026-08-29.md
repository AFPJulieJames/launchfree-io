Hard rules, restated because they matter every session:

- **Never run git. Not even `git status`.** Julie commits and pushes in GitHub Desktop.
- Every listing page is built from `docs/LISTING_TEMPLATE_SSR.html`. Never `template.html`, never by
  copying another page.

- One slug, decided once, never renamed.
- Every new listing touches six surfaces: the page, `listings.json`, `sitemap.xml`, `llms.txt`,
  `directory.html`, and its category page.
- Run `python3 docs/validate_build.py` before every commit. Must report 0 errors.
