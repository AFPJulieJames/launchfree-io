## What was fixed

**Every listing page rebuilt to one shape.** The repo held two different page structures, 62 tabbed
and 173 stacked, because pages were generated by different methods over time. All 235 are now
rendered from `docs/LISTING_TEMPLATE_SSR.html`. Content, slugs and URLs are unchanged, so nothing
de-indexes. The diff is large but mechanical.

**Three live 404s removed.** `kuroai`, `interakly` and `freecolortool` each had a related-launch
card pointing at `nanobanana.html`, which does not exist. Related cards are now generated from
`listings.json`, so a card can only point at a page that is really there.

**Category pages brought current.** They were stale at 179 launches while the site had 235, which
meant 56 launches had no category page link and no crawl path except the sitemap. All 17 now match
`listings.json`, with counts and ItemList schema refreshed.

**Schema completed.** The six original May seed listings had no `SoftwareApplication` or
`BreadcrumbList` JSON-LD. Every page has both now, plus a robots meta, which 70 pages were missing.

**Dead code removed.** 42 pages carried a legacy `LF_SLUG` vote script alongside the Supabase one.
`index.html` and `browse.html` carried an old Airtable path and a stale six record seed array.
Worth knowing why that mattered: `index.html` only read `listings.json` because the Airtable key
was still a placeholder string, so pasting a real key in there would have silently switched the
homepage to Airtable data. Both files now fetch `listings.json` and nothing else. A dead
`/css/content-shared.css` link was 404ing on 32 pages and is gone.

**House style enforced.** No em dashes remain in body copy anywhere, on listing pages, landing
pages or radar articles. The only ones left are the page-title separator and the `LaunchFree.io`
brand lockup, both structural. Where a dash introduced a short label it became a colon, where it
joined a clause it became a comma, and numeric ranges kept a plain hyphen.

**Submit form matches the site.** It offered `Newsletter` and `Physical Product`, which have no
category page, and omitted `Entertainment` and `Lifestyle`, which do. Form and site now agree on
all 17 categories.

**Small data fixes.** Four records had drifted stage values (`Launched`, `Early access`) and are
normalized. One product name carried an em dash and now uses a colon. `sitemap.xml` lastmod dates
were refreshed on every page whose content changed.

**Retired files stubbed.** `template.html`, `docs/RUNBOOK.md` and
`The_Runway_New_Listings_Runbook.md` now say plainly that they are retired and point at
`BUILD_SPEC.md`. The old runbook contradicted itself: section 3.5 required server-rendered pages
while step 3 still said to build from `template.html`.
